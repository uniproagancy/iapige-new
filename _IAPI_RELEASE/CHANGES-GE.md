# ბოლო ცვლილება — მიწოდების დღის არჩევა და ფოსტის მონიშვნები

მიზეზი: დაკეცილი თარიღის ფილტრის გამო სხვადასხვა მიწოდების დღის შეკვეთები ერთად ჩანდა.
ახლა კონკრეტული დღის არჩევა, „დღევანდელი“, წინა/შემდეგი დღე და „ყველა თარიღი“ პირდაპირ გვერდის თავშია.
თარიღის არჩევისას ძველი კოპირების/რედაქტირების ფანჯარა იხურება; არჩეული დღის რაოდენობები,
მომწოდებლების სია და კოპირებული ტექსტი იმავე დღის შეკვეთებს ერგება. ძველი პერიოდის ბმულები მუშაობს.

ახალი პირადი ჩანართია „ფოსტით გასაგზავნი“. შეკვეთა ხელით ემატება მთელი შეკვეთის დონეზე,
შემდეგ ინიშნება „ავიღე“ და „ფოსტაზე ავტვირთე“. დაბრუნება და უკვე ატვირთულების გაფილტვრა შესაძლებელია.
რეგიონები ავტომატურად არ გამოიცნობა. საფოსტო API არ ერთვება. კურიერის/გადახდის მდგომარეობა არ იცვლება.
წყაროს შეცვლის, გაუქმების ან წაშლის შემდეგ საფოსტო ისტორია რჩება და გადამოწმების ნიშნით ჩანს.

მხოლოდ ორი არსებული ფაილია განახლებული: Procurement Index და მისი მთავარი Blade.
ექვსი ახალია: პირადი საფოსტო მოდელი/სერვისი/მიგრაცია, საფოსტო Blade და ქართული/ინგლისური ტექსტები.
ახალი მიგრაცია მხოლოდ ერთ პირად ცხრილს ქმნის. ძველი შეკვეთების მონაცემები არ გადატანილა ან შეცვლილა.

95 ტესტი / 1206 შემოწმება: წინა 71 უცვლელად + 24 ახალი, მათ შორის რეალური Livewire HTTP მოთხოვნა,
დღის გადართვა, კოპირებული სიის შეზღუდვა, საფოსტო მოქმედებები, როლები, განმეორება, ცვლილებების დაცვა,
ერთი შეკვეთის რამდენიმე ნივთის გაერთიანება, მიღებული ნივთისგან დამოუკიდებელი არჩევა და მრიცხველები.
რვავე ფაილი ზუსტად ემთხვევა ტესტირებულ და დაყენებულ ვერსიას.
ინსტალერის 23 შემოწმება კრძალავს ძველ მონაცემებზე SQL ჩაწერას და უშვებს მხოლოდ ახალ პირად ცხრილსა
და ერთ კონკრეტულ მიგრაციის ჩანაწერს. რეალურ კლიენტზე საფოსტო მონიშვნა ან შეტყობინება არ შესრულებულა.
პაკეტის აწყობისას საიტზე არაფერი შეცვლილა. წინა 111 პროგრამული ფაილი, ბეჭედი და ოფიციალური ფორმები დაცულია.
