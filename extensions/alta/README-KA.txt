IAPI · Alta — 1.0.0

ინსტალაცია (Chrome ან Edge)
1. გახსენი chrome://extensions (Edge-ში edge://extensions).
2. ჩართე Developer mode.
3. Load unpacked → აირჩიე ეს საქაღალდე (სადაც manifest.json დევს).
   ძველი „IAPI · Alta JSON“ (0.5.0) წაშალე, რომ ორი არ აგერიოს.
4. განახლებისას ფაილები ჩაანაცვლე და Extensions-ში დააჭირე Reload-ს.

მუშაობა
0. იმავე ბრაუზერში შედი iapi.ge/admin-ზე მფლობელის ანგარიშით.
1. დააჭირე ხატულას → გაიხსნება პანელი → „სიის ჩატვირთვა“.
   სია არის ალტას B2B მარაგი სერვერიდან (მინიმუმ 2 ცალი).
2. აირჩიე:
   - მხოლოდ ახლები — რაც საიტზე ჯერ არ არის (ფოტოებით);
   - მხოლოდ საიტზე არსებულები — ფასისა და აღწერის განახლება (ფოტოების გარეშე,
     თუ „ფოტოები … არსებულ პროდუქტებზეც“ არ მონიშნე);
   - ყველა.
   პირველად საცდელად რაოდენობაში ჩაწერე 3.
3. „დაწყება“. ალტა იხსნება ცალკე ჩანართში — ის არ დახურო. პანელი ღია დატოვე.
   პაუზა / გაგრძელება მუშაობს; პანელის ან ბრაუზერის დახურვის შემდეგაც
   შეგროვებული არ იკარგება — გახსენი და დააჭირე „გაგრძელებას“.
4. თუ ალტა შემოწმების გვერდს აჩვენებს, შეგროვება ჩერდება და ალტას ჩანართი
   გამოჩნდება. გაიარე შემოწმება და დააჭირე „გაგრძელებას“.
5. „ჩამოტვირთვა“ — ყველაფერი ერთ ფაილად. ბრაუზერი გკითხავს, სად შეინახოს;
   ფაილი პირდაპირ დისკზე იწერება, ამიტომ დიდი სიაც არ აჭედებს.
6. iapi.ge/admin → იმპორტი → JSON → მომწოდებელი „ალტა“ → ფაილი → ნახვა → შენახვა.

რას აკეთებს
- ფასი: ალტას საიტის ფასი, უცვლელად. ძველი ფასი — თუ ალტაზე გადახაზულია.
- მარაგი: მხოლოდ B2B სიიდან. ალტას ფილიალების რაოდენობა არ ითვლება.
- ფოტოები: პირველი 8, JPEG/PNG/WEBP-ად. AVIF ან დიდი ფოტო JPEG-ად გადაიხატება,
  რომ საიტმა მიიღოს (ფოტოზე ≤ 1 MB, პროდუქტზე ≤ 2 MB).
- ალტას გვერდებს წამში ერთზე ხშირად არ კითხულობს.
