# იაფის გაყიდვების ჩატი — Git-ის პაკეტი

1. გახსენით ZIP და საქაღალდეები `app`, `config`, `database`, `lang`, `public`, `resources` და `routes` გადაიტანეთ იაფის რეპოზიტორიის ფესვში.
2. საერთო ფაილებში ჩატის ინტეგრაცია შეიტანეთ თანდართული ცვლილებით. ის ამატებს მარშრუტებს, მენიუს და ვიჯეტს, შეკვეთის გაფორმებას ლიდიდან და ონლაინ ვიზიტორების ძველი ჩანაწერების გაწმენდას.

```sh
git apply --check IAPI-SALES-CHAT-integration.patch
git apply IAPI-SALES-CHAT-integration.patch
```

თუ საერთო ფაილები რეპოზიტორიაში განახლებულია ან ცვლილების ნაწილი უკვე არსებობს, შეიტანეთ პატჩიდან საჭირო მონაკვეთები მიმდინარე კოდში.

განთავსებისას განახორციელეთ მიგრაციები და განაახლეთ მარშრუტებისა და ხედების ქეში საიტის ჩვეული წესით.

```sh
php artisan migrate --force
php artisan route:clear
php artisan view:clear
```

ჩატის ჩართვა და API გასაღების მართვა ხელმისაწვდომია მფლობელის გვერდზე `/admin/sales-chat/setup`. ჩატის ცოდნა ადმინსა და ოპერატორს აქვთ `/admin/sales-chat/knowledge`-ზე. ჩატის გამართვის შემდეგ შეამოწმეთ ნომრით ლიდის მიღება, ოპერატორის მიერ „დავურეკე“-ს მონიშვნა და მიწოდების გრაფიკის პასუხი.
