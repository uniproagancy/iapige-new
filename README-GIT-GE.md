## გამოყენება

„მომწოდებლებთან შეკვეთების“ თავში „მიწოდების დღე“ აირჩიე ან „დღევანდელს“ დააჭირე.
„ყველა თარიღი“ ძველ და მომავალ შეკვეთებს ერთად აჩვენებს. დან/მდე პერიოდიც შენარჩუნებულია.
თარიღის არჩევა მოდელების რაოდენობას, შესაკვეთსა და კოპირებულ სიასაც ფილტრავს.

იმავე გვერდზე გახსენი „ფოსტით გასაგზავნი“, აირჩიე შეკვეთა და დაამატე.
შემდეგ მონიშნე „ავიღე“ და „ფოსტაზე ავტვირთე“. სტატუსით უკვე ატვირთულებს ნახავ.
ერთი შეკვეთა ერთი ჩანაწერია, რამდენიმე ნივთისა და მომწოდებლის შემთხვევაშიც.
შეცდომით მონიშვნა ბრუნდება. ეს არის ხელით მონიშვნა; საფოსტო სისტემაში რეალური ატვირთვა არ ხდება.
პირადი გვერდი კვლავ მხოლოდ ადმინს აქვს. მონიშვნები კურიერისა და გადახდის სტატუსს არ ცვლის.

## Git-ში ჩასმა

ZIP გახსენით და app/, config/, database/, lang/, resources/, routes/ საქაღალდეები
არსებული Laravel პროექტის მთავარ საქაღალდეში შეაერთეთ. payload/ ფოლდერი არ არის.
Git-ის ცვლილებები შეადარეთ; პარალელური სამუშაო შეინარჩუნეთ შერწყმისას.
არსებული ბაზა, .env/APP_KEY, იმპორტები და პირადი ფაილები შეინარჩუნეთ.
