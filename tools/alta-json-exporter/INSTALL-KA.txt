   ნიმუშია — ITEM_CODE_1/2 და რაოდენობები რეალური მონაცემებით შეცვალეთ.
2. item არის ალტას B2B კოდი, quantity — B2B-ში არსებული მარაგი, მათ შორის 0.
3. თუ კოდების ველი ცარიელია, დამუშავდება ფაილის სია. შევსებისას დამუშავდება
   მხოლოდ მითითებული კოდები.
4. შეგროვების შემდეგ იმპორტის JSON-ში ფასი მოდის ალტას დეტალებიდან,
   მარაგი — B2B ფაილიდან. უცნობი მარაგით იმპორტის ფაილი არ შეიქმნება.

მარაგის სიის ვადა
სერვერის ბმულით მიღებული მარაგის სია 26 საათის შემდეგ მოძველებულად ითვლება.
ამ დროს ახალი შეგროვება, გაგრძელება და იმპორტის JSON დაიბლოკება;
საწყისი JSON-ის ჩამოტვირთვა კვლავ შეიძლება. ჩატვირთეთ განახლებული სია.
არასწორი, გაუქმებული, დაკარგული ან მოძველებული სიის პასუხი ძველ შედეგებს არ შლის.
ძველი ვერსიიდან შემორჩენილი დაუდასტურებელი მარაგისთვის თავიდან ჩატვირთეთ სია ან ფაილი.
კოდებითა და საკუთარი ფაილით მუშაობა იაფის წვდომის გარეშეც შეგიძლიათ.

პაუზა და გაგრძელება
შეგროვებისას პანელი ღია დატოვეთ. დამხმარე ჩანართი ხელით სხვა გვერდზე არ გადაიყვანოთ.
პაუზა აჩერებს მიმდინარე სამუშაოს. ნაწილობრივი შედეგების ჩამოტვირთვაც შეგიძლიათ.
პანელის დახურვის შემდეგ გახსენით იგივე გაფართოება და აირჩიეთ გაგრძელება.
დაწყება ქმნის ახალ სამუშაოს; საჭირო ძველი შედეგები მანამდე ჩამოტვირთეთ.
თუ გვერდი ვერ იტვირთება ან შემოწმებას ითხოვს, სამუშაო ჩერდება და წინა შედეგები რჩება.
თუ საცავი სხვა პანელმა შეაფერხა, დახურეთ სხვა Alta JSON პანელები და განაახლეთ
მიმდინარე გვერდი. მხოლოდ სხვა პანელის დახურვა ამ შეცდომას არ გააქრობს.

რა ინახება
საწყისი JSON შეიცავს ზუსტად დამთხვევილი პროდუქტის სრულ API პასუხს.
იმპორტის JSON ცვლის product.storageQuantity-სა და availabilityInStores-ს,
რომ ალტას ფილიალების რაოდენობა B2B მარაგად არ ჩაითვალოს.
ალტას ძიებისა და დეტალების მოთხოვნებს ემატება Accept-Language: ka.
ეს წესი მოქმედებს მხოლოდ გაფართოების დამხმარე ჩანართში ამ ორ API მისამართზე.
ბრაუზერის ენის პარამეტრების შეცვლა არ გჭირდებათ. ენას საბოლოოდ ალტას API განსაზღვრავს.
ადრე შენახული ინგლისური პასუხები უცვლელად რჩება; ქართული პასუხების თავიდან
წამოსაღებად განახლების შემდეგ აირჩიეთ დაწყება და არა ძველი სამუშაოს გაგრძელება.
ფოტოების შენახვისას იმპორტის ფაილს ემატება iapiAssets — ფოტოს მისამართი და შიგთავსი.
საწყისი JSON უცვლელია; მასში ზუსტად მიღებული პასუხი და ფოტოების ბმულებია.
ფოტოებზე უარის, შეცდომის ან ლიმიტის გადაჭარბებისას სამუშაო ჩერდება,
მაგრამ უკვე მიღებული საწყისი JSON რჩება ჩამოსატვირთად. გაგრძელება შეეცდება
ამ პროდუქტის ფოტოების მიღებას, მისი API პასუხს თავიდან აღარ წაიკითხავს.
შეგიძლიათ გამორთოთ ფოტოების შენახვა და გააგრძელოთ მხოლოდ ბმულებით.
ფოტოზე ლიმიტია 1 MiB, პროდუქტზე ჯამში 2 MiB; მაქსიმუმ პირველი 8 უნიკალური ფოტო.
403-ს ან შემოწმების გვერდს გაფართოება არ უვლის გვერდს და ავტომატურად არ იმეორებს.
იმპორტის თითო ნაწილში მაქსიმუმ 100 პროდუქტი და 8 MiB JSON იქნება.
ჩამოსატვირთი ნაწილის ველში ჩანს ნაწილების რაოდენობა და პროდუქტის დიაპაზონი.
თითო ნაწილისთვის ცალკე დააჭირეთ იმპორტის JSON-ს; ყველა ნაწილი საჭიროა.
ძველი შენახული სამუშაო არ იშლება. პაუზაზე მყოფ ძველ სამუშაოს გაგრძელება
აკლებული ფოტოებით შეავსებს. ძველი დასრულებული სამუშაოსთვის აირჩიეთ დაწყება.
ფოტოების მონიშვნისას ძველი უფოტო სამუშაოს იმპორტი დაიბლოკება, რომ ფოტოები
ჩუმად არ გამორჩეს. ბმულებით ჩამოსატვირთად გამორთეთ მონიშვნა; ფოტოებისთვის
დაიწყეთ ახალი სამუშაო. საწყისი JSON ორივე შემთხვევაში ხელმისაწვდომია.
ფაილი თავად უნდა შეიტანოთ თქვენს ამტვირთავში. გაფართოება პროდუქტებს საიტზე არ ინახავს.
