2. Edge-ში გახსენით edge://extensions/ ან Chrome-ში chrome://extensions/.
3. ჩართეთ Developer mode, აირჩიეთ Load unpacked და მიუთითეთ საქაღალდე,
   რომელშიც manifest.json დევს.
4. გაფართოებებში გახსენით IAPI · Alta JSON. ხატულა ხსნის სამუშაო პანელს.
   Node.js-ის, PHP-ის ან სხვა პროგრამის დაყენება არ გჭირდებათ.

   examples/product-codes.txt-ში სამი საჯარო საცდელი კოდია.
2. საცდელად დატოვეთ რაოდენობა 3. 0 ნიშნავს შეყვანილ ყველა კოდს.
3. დააჭირეთ დაწყებას. ალტას API-ის გვერდი თვითონ გაიხსნება დამხმარე ჩანართში.
4. დასრულებისას დააჭირეთ საწყისი JSON. მასში სრული მიღებული პასუხები ინახება.

B2B მარაგით იმპორტის JSON
1. აირჩიეთ საკუთარი B2B JSON ფაილი. examples/b2b-template.json მხოლოდ ფორმატის
   ნიმუშია — ITEM_CODE_1/2 და რაოდენობები რეალური მონაცემებით შეცვალეთ.
2. item არის ალტას B2B კოდი, quantity — B2B-ში არსებული მარაგი, მათ შორის 0.
3. თუ კოდების ველი ცარიელია, დამუშავდება ფაილის სია. შევსებისას დამუშავდება
   მხოლოდ მითითებული კოდები.
4. შეგროვების შემდეგ იმპორტის JSON-ში ფასი მოდის ალტას დეტალებიდან,
   მარაგი — B2B ფაილიდან. უცნობი მარაგით იმპორტის ფაილი არ შეიქმნება.

არჩევითი ფუნქცია იაფის ადმინისტრატორისთვის
სექცია იაფის ადმინიდან სიის წამოღება საჭიროებს iapi.ge-ზე წვდომის ცალკე
დადასტურებას და იმავე ბრაუზერში ადმინისტრატორის მოქმედ სესიას.
სხვა მომხმარებელს შეუძლია კოდებით ან თავისი B2B ფაილით იმუშაოს.
გაფართოება B2B-ის პაროლს არ ითხოვს და SOAP ანგარიშს არ შეიცავს.

პაუზა და გაგრძელება
შეგროვებისას პანელი ღია დატოვეთ. დამხმარე ჩანართი ხელით სხვა გვერდზე არ გადაიყვანოთ.
პაუზა აჩერებს მიმდინარე სამუშაოს. ნაწილობრივი შედეგების ჩამოტვირთვაც შეგიძლიათ.
პანელის დახურვის შემდეგ გახსენით იგივე გაფართოება და აირჩიეთ გაგრძელება.
დაწყება ქმნის ახალ სამუშაოს; საჭირო ძველი შედეგები მანამდე ჩამოტვირთეთ.
თუ გვერდი ვერ იტვირთება ან შემოწმებას ითხოვს, სამუშაო ჩერდება და წინა შედეგები რჩება.

რა ინახება
საწყისი JSON შეიცავს ზუსტად დამთხვევილი პროდუქტის სრულ API პასუხს.
იმპორტის JSON ცვლის მხოლოდ product.storageQuantity-სა და availabilityInStores-ს,
რომ ალტას ფილიალების რაოდენობა B2B მარაგად არ ჩაითვალოს.
ალტას ძიებისა და დეტალების მოთხოვნებს ემატება Accept-Language: ka.
ეს წესი მოქმედებს მხოლოდ გაფართოების დამხმარე ჩანართში ამ ორ API მისამართზე.
ბრაუზერის ენის პარამეტრების შეცვლა არ გჭირდებათ. ენას საბოლოოდ ალტას API განსაზღვრავს.
ადრე შენახული ინგლისური პასუხები უცვლელად რჩება; ქართული პასუხების თავიდან
წამოსაღებად განახლების შემდეგ აირჩიეთ დაწყება და არა ძველი სამუშაოს გაგრძელება.
ფოტოები ფაილში ბმულებითაა.
ფაილი თავად უნდა შეიტანოთ თქვენს ამტვირთავში. გაფართოება პროდუქტებს საიტზე არ ინახავს.
