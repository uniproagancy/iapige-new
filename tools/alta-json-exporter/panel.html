ალტას პროდუქტის კოდები — სრულ JSON ფაილად.

1. პროდუქტის სია

წვდომის ბმულით სია ადმინში შესვლის გარეშე ჩაიტვირთება. კოდები და საკუთარი ფაილიც შეგიძლიათ გამოიყენოთ.

ბმულს მფლობელი გაძლევთ. იგი ამ ბრაუზერში შეინახება; სხვას მხოლოდ ნებართვით გაუზიარეთ.

მხოლოდ კოდებით სრულ საწყის JSON-ს მიიღებთ. B2B მარაგით იმპორტის ფაილისთვის სიის ფაილიც ჩატვირთეთ.

სიის შაბლონი ↓

შაბლონში კოდები და რაოდენობები თქვენი რეალური მონაცემებით შეცვალეთ. კოდების ველის შევსებით ჩატვირთული სიიდან კონკრეტულ პროდუქტებს აირჩევთ.

B2B სია ჯერ არ არის ჩატვირთული.

2. შეგროვება

პირველად ფოტოებზე წვდომას მოგთხოვთ. ერთ ფოტოზე მაქსიმუმ 1 MiB, პროდუქტზე ჯამში 2 MiB; ინახება პირველი 8 ფოტო. გამორთვისას მხოლოდ ბმულები დარჩება.

ჩატვირთეთ სია ან ჩასვით პროდუქტის კოდები.

ახალი მოთხოვნები იგზავნება ქართული ენის არჩევით. ადრე შენახული ინგლისური პასუხების თავიდან მისაღებად აირჩიეთ „დაწყება“.

3. ჩამოტვირთვა

იმპორტი დაიყოფა მაქსიმუმ 8 MiB / 100 პროდუქტის ნაწილებად. ჩამოტვირთეთ თითოეული ნაწილი ცალ-ცალკე.

ფოტოები ემატება მხოლოდ იმპორტის JSON-ს (iapiAssets). საწყისი JSON სრული და უცვლელია. საიტზე არაფერი იგზავნება.
